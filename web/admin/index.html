Energy Trading — Admin

Manage household/producer registration, Oracle write access, and battery management. Write actions go through MetaMask; each action picks the correct connected wallet for its required role automatically.

Register household / producer

Households: OracleStorage.registerHousehold() (needs an Oracle-authorized wallet), then P2PEnergyMarket.registerHousehold() (needs the Market owner). Producers only need the second step — the contract doesn't require Oracle registration for producers.

Oracle write access

OracleStorage.authorizeOracle() / revokeOracle() — needs the OracleStorage owner. This grants or revokes permission to write meter/weather/battery data, not registration status.

Battery management

BatteryManager.addHousehold() — needs the BatteryManager owner and a household already registered in OracleStorage. There's no remove function on the contract, so this can't be undone from here. Battery status for existing households is shown in the table below.
