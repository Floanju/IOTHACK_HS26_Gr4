Advanced — overrides & known households
BatteryManager and IncentiveController are normally read straight off the market contract (batteryManager() / incentiveController()). Overrides here are only useful if you want to inspect one before it's linked via setBatteryManager() / setIncentiveController(). OracleStorage has no enumeration function, so a household that only reports meter data but isn't market-registered yet can only be found through the list below — it's automatically unioned with market.getAllHouseholds().
