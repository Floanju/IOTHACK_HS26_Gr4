Lookback window

Trade and transfer history is read via eth_getLogs over the last N blocks (no indexer/API key needed). Some public RPC providers cap the block range per request — lower this if a reload errors out. ~10000 blocks is roughly a day+ of buffer at Sepolia's ~12s block time; the "last 24h" columns below filter down to real timestamps within that window.
