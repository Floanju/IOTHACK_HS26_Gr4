Energy Trading — Transactions

Last settlement, per-account balances, and energy exchanged between accounts. Read-only — no wallet needed.

Lookback window

Trade and transfer history is read via eth_getLogs over the last N blocks (no indexer/API key needed). Some public RPC providers cap the block range per request — lower this if a reload errors out. ~10000 blocks is roughly a day+ of buffer at Sepolia's ~12s block time; the "last 24h" columns below filter down to real timestamps within that window.

Last settlement

Green bars are what an account received in the last settlement, red bars are what it paid — sorted from received the most (left) to paid the most (right), each bar scaled relative to the largest amount involved.
